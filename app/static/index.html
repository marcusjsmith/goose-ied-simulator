Parameter Reference

Fields shown when you expand a message in the log.

Message header
STATE CHANGE
Dataset value changed; stNum incremented.
RETRANSMIT
Periodic refresh with unchanged data; only sqNum advances.
stNum / sqNum
Quick summary of state and sequence numbers for the frame.
Ethernet header
Destination MAC
IEC 61850 multicast address (01-0C-CD-01-00-XX) — all subscribers listen on this MAC.
Source MAC
MAC address of the publishing IED port.
EtherType
0x88B8 identifies a GOOSE ethertype frame.
APPID
Application ID — distinguishes this GOOSE stream on the substation LAN.
Length
Length of the GOOSE PDU payload in bytes.
GOOSE PDU
gocbRef
GOOSE control block reference (e.g. IED/LLN0$GO$GcbName).
datSet
Dataset bound to this GoCB — lists the logical-node attributes being published.
goID
Human-readable GOOSE identifier for operators and configuration tools.
timeAllowedToLive
Maximum time (ms) before subscribers treat the message as expired if no update arrives.
t
UTC timestamp of the event or publication instant.
stNum
State number — increments whenever any dataset value changes.
sqNum
Sequence number — increments on every transmission, including retransmits.
confRev
Configuration revision — bump when GoCB or dataset membership changes.
test
TRUE = test mode; protection functions should ignore the message.
ndsCom
TRUE = dataset not yet commissioned; data may be incomplete.
numDatSetEntries
Number of encoded values carried in the dataset.
Dataset payload
#
Zero-based index of the entry in the published dataset.
Reference
MMS object reference (logical node + data attribute path).
Type
MMS type: boolean, dbpos, quality, float32, etc.
Value
Decoded engineering value (position, measurement, quality flag, …).
BER Hex
ASN.1 BER encoding of this entry as sent on the wire.
Full frame hex
Full Frame Hex
Complete Ethernet frame (header + GOOSE PDU) as hexadecimal bytes for protocol analysis.
